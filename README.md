# TradeHire Quote Tool (demo)

A demo of the TradeHire NZ quote tool, built by Webbased AI. Type or say any New Zealand address and the building is measured live in the browser from LINZ's free open data: the official building outline, each wall's height from the newest 1 m laser scan, roof pitch and the newest aerial photo. Then mark the walls (scaffold, shrink wrap, edge protection, power lines) and see the quote lines.

Prices are hidden in this public demo. AroFlo answers are examples; nothing is saved anywhere.

LINZ data is used under CC BY 4.0 (Toitū Te Whenua Land Information New Zealand).

Built from the private tradehire-quoting repo (`python3 tool/build.py`, output in `tool/web-dist/`).
